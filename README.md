Конфиги реализованы через ScriptableObject-ы.
В папке Configs настройки игрока - PlayerConfig.
Enemies - список типов врагов.

Изначально реализовано два вида врагов - ZombieGirl и Romero. Их настройки можно изменить в папке Configs/EnemyTypes.

Чтобы добавить нового врага, нужно создать объект настроек (SO Configs->New Enemy Type), указать характеристики врага и файл 3д модели
персонажа, и добавить объект в Enemies. 
Можно было сделать автоподгрузку всех видов врагов в проекте без отдельного списка Enemies, но тогда они все были бы включены в список спауна всегда,
и не было бы возможности кого-то намеренно исключить.

!!Важно!! - при импорте новых моделей для врагов, нужно указывать в настройках импорта Rig->Avatar Definition->Create from this model.

Все враги включенные в список Enemies в конфигах будут включены в список спауна врагов в игре, и распределены среди врагов равномерно.
